# 02 — pi (the coding agent)

[pi](https://github.com/earendil-works/pi) is the coding agent that everything else in
this environment hangs off. It's a terminal coding agent (a "pi-mono" coding-agent
package) with a provider registry, extensions, skills, MCP support, and session
management. On this machine it is the single agent: the local 27 B model is its brain
(`docs/04-splash.md`), extensions add iMessage, MCP, and a git footer
(`docs/05-extensions.md`), and MCP servers add Apple Music and Safari
(`docs/06-mcp.md`).

## Source & install

| | |
|---|---|
| Upstream repo | `github.com/earendil-works/pi` (package: `packages/coding-agent`) |
| npm package | `@earendil-works/pi-coding-agent` |
| Version in use | **1.3.0** |
| Install | `brew install pi` (Homebrew cask; the cask installs the npm package, so `pi` resolves to `/opt/homebrew/bin/pi`) |
| Runtime | Node.js (v25 here, via Homebrew) |

Upgrades: `brew upgrade pi`. When the version changes, re-verify the
`settings.json` keys below against the changelog — pi moves fast.

## The config directory: `~/.pi/agent/`

Everything pi loads globally lives in `~/.pi/agent/` (override with `PI_CODING_AGENT_DIR`
if you must). The repo vendors the stable, personal-free subset under `pi/`; the rest is
generated or personal and is gitignored:

| Path (in `~/.pi/agent/`) | Purpose | Status |
|---|---|---|
| `settings.json` | User settings (below) | **vendored** (`pi/settings.json`) |
| `permissions.json` | Tool permission rules | **personal — not vendored** (below) |
| `models.json` | Custom providers (the `splash` provider) | **vendored** (`pi/models.json`, `docs/03-models.md`) |
| `mcp.json` | MCP servers | **templated** (`pi/mcp.json.template` + `.env`, `docs/06-mcp.md`) |
| `SYSTEM.md` | Global system prompt (the "global AGENTS.md") | **vendored sanitized** (`pi/SYSTEM.md`; the phone number is `{{PI_NOTIFY_PHONE}}`) |
| `agents/` | *(none)* | — |
| `extensions/` | Local extension repos, symlinked in | generated/personal (`docs/05-extensions.md`) |
| `skills/` | Skill repos, symlinked in | generated/personal (`docs/05-extensions.md`) |
| `npm/` | `npm:` package extensions (`node_modules`) | generated |
| `bin/` | `fd`, `rg` binaries bundled with the pi package | generated |
| `pi-imessage/` | config for the local iMessage extension (handles = personal) | personal |
| `auth.json` | API keys for cloud providers | **personal — never committed** |
| `models-store.json` | auto-generated model registry cache (~80 KB) | generated — never committed |
| `mcp-cache.json` | MCP server metadata cache (~60 KB) | generated — never committed |
| `sessions/`, `todos/`, `pi-memory/`, `logs/` | session transcripts, task store, memory, logs | generated/personal — never committed |

## `settings.json` (vendored as-is)

| Key | Value | Why |
|---|---|---|
| `theme` | `dark` | UI preference. |
| `transport` | `auto` | pi auto-selects the model transport; works for the local OpenAI-compatible Splash endpoint. |
| `packages` | `npm:@firstpick/pi-extension-git-footer-status`, `npm:pi-mcp-adapter` | the two npm extensions installed globally (`docs/05-extensions.md`). |
| `defaultProvider` / `defaultModel` | `splash` / `splash/mlx-community/Qwen3.8-27B-4bit` | everything defaults to the local 27 B model (`docs/03-models.md`). |
| `enabledModels` | the three Splash models | only local models are offered; cloud keys in `auth.json` exist but no cloud models are enabled in the picker. |
| `defaultThinkingLevel` | `xhigh` | the 27 B thinks hard by default (Qwen thinking-budget map in `models.json`). |
| `followUpMode` / `steeringMode` | `one-at-a-time` | queued follow-ups and mid-task steering messages are processed one at a time — less context churn on a 74 K local context. |
| `markdown.mermaid` | `on` | render mermaid diagrams in the TUI. |
| `defaultProjectTrust` | `ask` | untrusted project dirs prompt before pi reads/writes — matters because pi auto-loads `AGENTS.md` from whatever repo you cd into. |
| `doubleEscapeAction` | `tree` | double-escape opens the session tree (history/branching view). |
| `compaction` | enabled, `reserveTokens` 16384, `keepRecentTokens` 6000, per-model reserve overrides (25600 / 20480 / 20480) | context management sized for 64–74 K local windows; the overrides reserve more output budget for the dense models (`docs/03-models.md`). |
| `retry` | enabled, 6 retries, 20 s base delay | the local server occasionally hiccups under load; retry with backoff instead of failing the turn. |
| `extensions` | `["-builtin:mcp"]` | **disables pi's built-in MCP client** in favor of the `pi-mcp-adapter` package, which bridges the two MCP servers in one integration (`docs/06-mcp.md`). |
| `httpIdleTimeoutMs` | 0 | no idle timeout for local HTTP (the 27 B can think for minutes mid-stream). |
| `tuiMode` / `fullscreenScrollbar` / `showHardwareCursor` / `terminal.showTerminalProgress` | `regular` / `auto` / `true` / `true` | cosmetic TUI tuning. |

## `permissions.json` (not vendored)

The live file on this machine carries a few ad-hoc tool allow-rules; it's
personal, so the repo ships no copy. A mirror starts from pi's defaults (every
tool call asks first) and adds rules as needed — keep the allow list short, pi
will otherwise prompt constantly.

## The "global AGENTS.md"

pi has two instruction-file layers:

1. **Per-project**: `AGENTS.md` in a repo root (also `AGENTS.override.md`, with
   `CLAUDE.md` as a fallback). Loaded automatically when pi starts in that project.
   Each of the working repos on this machine carries its own `AGENTS.md`; they are
   project files, not part of this config repo.
2. **Global**: `~/.pi/agent/SYSTEM.md` — replaces pi's base system prompt for *every*
   session in every project. (`APPEND_SYSTEM.md` would add to it instead of replacing;
   not used here.)

The global `SYSTEM.md` on this machine is a working-agent contract: be useful before
being careful, ask only on real ambiguity, verify before claiming done, and **send an
iMessage when a task finishes**. This repo vendors a sanitized copy (`pi/SYSTEM.md`)
where the only personal value — the notification phone number — is the
`{{PI_NOTIFY_PHONE}}` placeholder that `scripts/render.sh` fills from `.env`.
